## Запуск

Команды выполняются из папки `lab1`:

```sh
cp .env.example .env
docker compose up --build
```

В Windows PowerShell вместо первой команды: `Copy-Item .env.example .env`.
Открыть http://localhost:5000/hello — каждый запрос записывает посещение в PostgreSQL.
Остановка: `docker compose down`. Данные остаются в томе PostgreSQL.
ЛР1 и ЛР3 используют порт 5000: запускайте их по отдельности.
