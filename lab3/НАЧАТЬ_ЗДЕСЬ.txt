Лабораторная работа 3 — Библиотека

1. Распакуйте архив целиком.
2. Основной запуск для защиты — через установленный и запущенный Docker:
   откройте терминал в папке rpp_lab3 и выполните:
   docker compose up --build
3. Откройте http://localhost:5000 в браузере.

Дополнительный локальный запуск с Python 3.12 или новее:
Windows: откройте START_WINDOWS.bat.
macOS/Linux: в терминале выполните sh start.command.
После запуска откройте http://127.0.0.1:5000.
Скрипты при первом запуске скачивают зависимости — нужен интернет.

Если порт 5000 занят, после установки зависимостей выполните:
python run.py --port 5001
и откройте http://127.0.0.1:5001.

Начальные данные: книга book-1 и читатель reader-1.
Читатель: Забронировать.
Библиотекарь: Выдать → Принять возврат → Зафиксировать осмотр →
Рассчитать штраф → Вернуть в фонд → Закрыть выдачу.
ИС: управление временем и демонстрация таймеров.

Подробности, команды API и условия расчёта штрафа — в README.md.
Данные хранятся в памяти и очищаются при перезапуске программы.
Проверку запуска контейнера Docker необходимо выполнить на ПК с Docker.
