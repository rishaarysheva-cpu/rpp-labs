# Лабораторная работа 2

Проектирование доменной модели с помощью DDD. Предметные области: библиотека и прокат самокатов.

[Исходный отчёт Word](docs/Лабораторная%20работа_2.docx) содержит инварианты, агрегаты, репозитории, сценарии проверки и исходный код в приложениях А и Б.

В исходном документе код сохранён изображениями. Отдельные файлы `library_domain.py` и `scooter_domain.py` в найденных материалах отсутствуют, поэтому запускаемых исходников в этой папке пока нет.

[Лабораторная работа 3](../lab3/) развивает модель библиотеки: состояния выдачи, очередь, таймеры, продление и штрафы.
